# Syncd: Band Collaboration App

### **Overview**
Syncd is a mobile app designed to revolutionize communication and collaboration for musicians and bands. By consolidating critical information into a single platform, Syncd minimizes confusion and streamlines planning for events, rehearsals, and tasks. Whether you're managing gigs or coordinating rehearsals, Syncd keeps your band organized, stress-free, and ready to perform.

---

### **Background**
Effective communication is a significant challenge for many bands. Existing tools like Messenger often lead to lost information and miscommunication, making it difficult to stay on top of deadlines and events. Syncd addresses these issues by offering a structured, centralized platform for all band-related needs, improving productivity and reducing stress.

---

### **Features**

#### **1. Dashboard**
- Provides an overview of upcoming tasks that are assigned to you upon login.
- Events are displayed as intuitive cards with titles, descriptions, and dates.

#### **2. Personal To-Do List**
- Each user has a private "SCRUM-board" to track their tasks.
- Tasks are added to the board by the admin.

#### **3. Event Management**
- Handles various events, including rehearsals, recordings, gigs, and photoshoots.
- Keeps all members informed about event details and updates.

#### **4. User Roles and Permissions**
- Different roles (e.g., admin, member) to manage access rights.
- Admins can create and edit events for the group.

---

### **Technology Stack**

#### **Frontend**
- Developed with Android Studio using Jetpack Compose for a modern, intuitive user interface.

#### **Backend**
- Powered by Spring Boot and MariaDB for authentication and data storage.
- Provides robust and reliable backend services using JWT, hashing and other security solutions.

---

### **Design Philosophy**
- **User-Friendly:** A clean, modern interface ensures users can easily navigate and access key features.
- **Efficiency-Focused:** Reduces time spent searching for information and streamlines planning.
- **Collaborative:** Enhances teamwork by making task management seamless.

---

### **Benefits**
With Syncd, musicians and bands can:
- Stay updated on events without digging through message threads.
- Collaborate effectively using organized to-do lists and clear deadlines.
- Minimize miscommunication and improve planning for rehearsals, recordings, and performances.

### **Getting Started**

#### **Prerequisites**
- Android device (minimum API level 30).

#### **Installation**
1. Clone this repository: `git clone https://github.com/JoBch/BerellStudios-Examensarbete`
2. Open the project in Android Studio.
3. Sync the project dependencies and run the app on your preferred emulator.

#### **Running the Backend**
1. Navigate to the backend directory.
2. Build the Spring Boot application: `./mvnw spring-boot:run`.
3. Ensure MariaDB is running and configured properly.
